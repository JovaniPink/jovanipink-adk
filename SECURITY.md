# Security Policy

This project is in pre-release development. Do not use it with production data, credentials, write-capable tools, or customer-authored skills.

To report a suspected vulnerability, use GitHub's private vulnerability reporting feature after the repository is public. If that feature is unavailable, contact the repository owner privately. Do not open a public issue containing secrets, private product details, customer information, exploit credentials, or a working attack against a real system.

Include the affected source revision, adapter and ADK versions, a minimal synthetic reproduction, expected behavior, observed behavior, and whether any private data or credential may have been exposed.

Security fixes may revoke bundle versions immediately. A revoked bundle remains rejected even in test mode.
